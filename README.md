# Overview

This README provides an overview of my prefered work style, communication methods, etc

## Prefered Communication Methods

I prefer [async communication](https://handbook.gitlab.com/handbook/company/culture/all-remote/asynchronous/).

- Knowledge Share: Documentation (always respond with a link)
- Project Related: Ticket/Work-Item Comment
- Status Updates: Dashboards or Ticket/Project Tracker
- Anouncements: Email or Blog Posts
- Urgent Issues: Chat or Phone Call
- Memes/Jokes/Fun/Culture: Chat
- Quick Syncs: Chat or Video Call
- Else: Email

### Related:

- [How to embrace asynchronous communication for remote work](https://handbook.gitlab.com/handbook/company/culture/all-remote/asynchronous/)
- [Group Chat: The Best Way to Totally Stress Out Your Team](https://37signals.com/group-chat-problems)

## Prefered Work Style

Still tweaking but generally:

- Meetings and async comms respones in the morning

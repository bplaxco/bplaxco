# Workflow

I figured I'd start trying to formalize my day-to-day workflow because:

- I'm quirky
- I wanted to see if I could improve some things by mapping it out.

I'm sharing it here because:

- Well I'm quirky
- I like open source and it make it easier to share in case it becomes 
  something worth sharing over time.
- If someone has an idea, it'd be neat to hear from them.
